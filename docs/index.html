How to use them

  1. Download the SVG files (vector, one colour, real size in millimetres). They suit flex or flock printing, which is durable on sports shirts. Use the PNG files (transparent, 300 dpi) for digital printing.
  2. Upload front and back to the print-on-demand shop of your choice, for example Spreadshirt, and check its current upload requirements.
  3. Recommended look: text colour #FFF8E7 (warm off-white) on a royal-blue shirt. All fronts share one canvas width (28 cm), all backs too – scale every design of one side to the same width and the series stays consistent.
  4. Want your own verb? The generator in the repository renders new texts in the same style.
