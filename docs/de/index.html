So nutzt du sie

  1. Lade die SVG-Dateien herunter (Vektor, einfarbig, echte Größe in Millimetern). Sie eignen sich für Flex- oder Flockdruck, der auf Sportshirts besonders haltbar ist. Für Digitaldruck nimmst du die PNG-Dateien (transparent, 300 dpi).
  2. Lade Vorder- und Rückseite beim Print-on-Demand-Anbieter deiner Wahl hoch, zum Beispiel bei Spreadshirt, und prüfe dessen aktuelle Upload-Anforderungen.
  3. Empfohlener Look: Textfarbe #FFF8E7 (warmes Off-White) auf einem königsblauen Shirt. Alle Vorderseiten haben dieselbe Breite (28 cm), alle Rückseiten ebenso – skaliere alle Designs einer Seite auf dieselbe Breite, dann bleibt die Serie einheitlich.
  4. Lust auf ein eigenes Verb? Der Generator im Repository setzt neue Texte im selben Stil.
